Hosting Variable Fonts Locally

Created by Craig Webb at Github.com/cwebba1/Variable-font-libraries

Why Host Fonts Locally?

Hosting fonts locally on a website offers several advantages over relying on third-party font hosting services like Google Fonts. Here are five key reasons to do so:

  • Improved Performance and Speed
  • Increased Control
  • Reliability and Independence
  • Better Privacy and Security
  • Reduced Risk of FOUC (Flash of Unstyled Content)

Load fonts locally using CSS:


@font-face {
  font-family: 'YourFont';
  src: url('your-font-name.woff2') format('woff2'),
       url('your-font-name.woff') format('woff');
  font-style: normal;   /* Or italic */
  font-weight: 100 900;  /* Range of weights */
  font-stretch: 75% 125%; /* Range of widths */
  format('woff2-variations');
}

What are Variable Fonts?

Variable fonts are a type of font that allows a single font file to contain multiple variations of the font style, weight, width, and other properties which can be adjusted dynamically.

Key features of
variable fonts:

  • Multiple Axes of Variation
  • Efficiency in File Size
  • Dynamic Styling
  • Improved Performance
  • Greater Flexibility

What format is best for hosting Variable Fonts locally?

WOFF2 (Web Open Font Format 2): This format supports variable fonts and is the most widely used for web purposes due to its compression, which reduces file sizes without sacrificing quality.

In Terminal – Converting Variable Fonts to woff2

Loading the program


craigwebb@Hero ~ % cd Documents/Variable-Sans-Serif-Fonts

craigwebb@Hero Variable-Sans-Serif-Fonts % git clone --recursive https://github.com/google/woff2.git
cd woff2

Converting fonts from .ttf to .woff2: 



craigwebb@Hero woff2 % ./woff2_compress ~/Documents/Variable-Sans-Serif-Fonts/Figtree/Figtree-Italic-VariableFont_wght.ttf
